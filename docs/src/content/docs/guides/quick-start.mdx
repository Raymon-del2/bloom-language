Welcome to Bloom! This guide will get you from zero to a running application in just a few minutes.

## Prerequisites

Before you begin, make sure you have:

- **Python 3.8+** installed on your system
- A terminal/command prompt
- Your favorite code editor

## Installation

<Steps>

1. **Install Bloom via pip:**

   ```bash
   pip install bloom-framework
   ```

   :::tip[Add pip to PATH]
   If you see "pip is not recognized", add pip to your system PATH:

   ```powershell
   # Replace 3.12 with your Python version
   [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Users\$env:USERNAME\AppData\Local\Packages\PythonSoftwareFoundation.Python.3.12_qbz5n2kfra8p0\LocalCache\local-packages\Python312\Scripts", "User")
   ```

   Then **restart your terminal** and try again.
   :::

2. **Verify the installation:**

   ```bash
   bloom --version
   ```

   You should see something like `Bloom v1.0.0 🌱`

3. **Plant your first Seed:**

   ```bash
   bloom seed my-first-app
   cd my-first-app
   ```

4. **Grow your application:**

   ```bash
   bloom grow
   ```

5. **Open your browser:**

   Navigate to `http://localhost:8080` to see your app running!

</Steps>

## What's Next?

Your Bloom application is now running with:

- Live reload (changes appear instantly)
- The Sieve security system active
- Pulse monitoring enabled
- A development HUD visible in the corner

Try editing `src/main.py` and watch your changes appear immediately in the browser!

## Common Commands

| Command | Description |
|---------|-------------|
| `bloom seed <name>` | Create a new project |
| `bloom grow` | Start development server |
| `bloom crystalize` | Build for production |
| `bloom plant` | Deploy to hosting |

Ready to learn more? Check out [Your First Seed](/guides/first-seed/) to understand the core concepts.
